About 

Phising Detector Academy is an educational web platform designed to help users identify and protect themselves against online phising attacks and social engineering threats.

Purpose of this project

This web platform targets users to raise their cybersecurity awareness by providing interactive learning materials to recognize malicious links, fraud emails, deceptive websites before falling to be victim to them. 

Main features

- Phishing Detection Tools: Features to analyze and check suspicious links or content indicators.
- Interactive Modules: Practical lessons breaking down real-world phishing tactics (email spoofing, domain manipulation, sense of urgency, etc.).
- Visual Indicators & Examples: Comparisons between legitimate communications and malicious attacks.
- Quizzes: Quick tests to evaluate phishing recognition skills.
